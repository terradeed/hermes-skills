# TerraDeed Skills for Hermes Agent

Web data extraction skills for [Hermes Agent](https://hermes-agent.nousresearch.com/) by [TerraDeed Labs](https://terradeed.co.uk).

## Install

```bash
hermes skills tap add terradeed/hermes-skills
hermes skills install terradeed-web-data-extraction
```

## What You Get

Three tools for extracting structured data from any public URL:

| Tool | Price | Returns |
|------|-------|---------|
| **scrape_url** | $0.01 USDC | Clean, LLM-ready markdown |
| **extract_data** | $0.05 USDC | Structured JSON with named fields |
| **extract_property** | $0.10 USDC | UK commercial property intelligence |

No API key required. Uses [x402](https://x402.org/) micropayments on Base mainnet.

## Requirements

- Hermes Agent (or any agentskills.io-compatible agent)
- USDC on Base mainnet for x402 payments
- Or contact TerraDeed for API key access
